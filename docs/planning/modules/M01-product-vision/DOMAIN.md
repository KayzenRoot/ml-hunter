# M01 Domain
Status: PLAN-COMPLETE

Canonical vocabulary: Opportunity = evidence-backed candidate action, never a profit guarantee; Evidence = traceable observation/input; TruthClass = OBSERVED | DERIVED | ESTIMATED | UNKNOWN; Recommendation = explainable proposed action; Decision = attributable accepted/rejected/deferred choice; Outcome = realized result linked to the decision; Tenant = isolation boundary; Source/Marketplace = capability-described external domains; AutomationMode = MANUAL | ASSISTED | AUTOPILOT and never authorization.

Conceptual chain: Evidence -> Fact/Estimate -> Opportunity -> Recommendation -> Decision -> Action -> Outcome -> Learning.

Invariants: UNKNOWN is never invented away; ESTIMATED carries method/version/confidence where applicable; OBSERVED carries source/time/provenance; outcomes never rewrite decision-time evidence; automation mode cannot bypass authorization, financial guards or tenant policy.
